Drop-In Integration

Integrate this WebGL 2.0 silk raymarcher into any web project in under 3 lines of JavaScript.

// 1. Import modular RaymarchedSilkWaves ES Module
import { RaymarchedSilkWaves } from './js/raymarch-waves.js';

// 2. Instantiate with Dark Luxury defaults (Speed 0.25, Damped Scroll)
const waves = new RaymarchedSilkWaves({
  speed: 0.25,          // Requested sinusoidal speed
  waveHeight: 1.25,     // Ethereal silk amplitude
  waveFreq: 0.62,       // Organic harmonic density
  grainIntensity: 0.045 // Anti-banding film grain
});

// 3. Automatic continuous scroll synchronization & mouse parallax are active!
